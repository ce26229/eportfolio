# MSc Information Technology Management ePortfolio

This is Chris Evans’s academic portfolio. The home page is `index.html`. The website is published from the root of the `main` branch on [GitHub Pages](https://ce26229.github.io/eportfolio/).

## Adding work

Give the module name and the item you want to add. For an artefact, supply the file or link, what it demonstrates and any feedback you want to include. For a reflection, start with your own notes on what you learnt and how. Dates use DD/MM/YYYY.

Each module has a separate HTML file under `modules/`. Update the relevant section there. The directory is `modules.html` and the profile is `about.html`. GitHub keeps earlier revisions. Changes saved to the publishing branch appear on the live site.

## Sources

Module outcomes are summarised from the University of Essex Online MSc Information Technology Management course brochure. The site adapts [Forty by HTML5 UP](https://html5up.net/forty). The design licence is in `LICENSE.txt` and credits are listed on the website.
